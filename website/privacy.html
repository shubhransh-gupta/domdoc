Privacy Policy

Last updated: August 8, 2026

Page Audit is a browser extension that audits web pages for performance, accessibility, SEO, and UX issues.

Data collection

We do not collect, store, or transmit any personal data. All analysis happens locally in your browser.

What the extension does

  • Reads the current page when you click "Test This Page"
  • Runs checks using built-in scripts and axe-core
  • Shows results in the extension popup
  • Highlights elements on the page when you click an issue

Permissions

  • activeTab — used only when you open the extension on the current tab
  • scripting — used to run the audit when you request it

Contact

If you have questions, please open an issue on GitHub.
