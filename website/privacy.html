Privacy Policy

Last updated: August 8, 2026

Page Audit ("the Extension") is a browser extension that audits web pages for performance, accessibility, SEO, and UX issues. Your privacy is important to us.

Data Collection

We do not collect, store, or transmit any personal data. The Extension runs entirely in your browser on the page you choose to audit.

What the Extension Does

  • Analyzes the current webpage's DOM, styles, and performance metrics locally
  • Runs accessibility checks using the bundled axe-core library
  • Displays results in the extension popup
  • Optionally highlights elements on the page when you click an issue

Permissions Explained

  • activeTab — Allows the extension to analyze the page you are currently viewing when you click the extension icon
  • scripting — Injects the audit script into the active tab only when you request an audit

The Extension does not access tabs in the background. It only runs when you explicitly click "Test This Page".

Third-Party Services

The Extension does not connect to any external servers. All analysis happens locally. The axe-core library is bundled within the extension and does not make network requests.

Data Storage

The Extension does not persist audit results or browsing history. Closing the popup clears the session.

Children's Privacy

The Extension is a developer tool and is not directed at children under 13.

Changes

We may update this policy. Changes will be posted on this page with an updated date.
