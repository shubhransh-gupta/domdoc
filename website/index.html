What it checks

Fast heuristic audits for day-to-day development — not a full CI Lighthouse replacement, but instant feedback while you build.

⚡

Performance

DOM size, page weight, load time, render-blocking scripts, and layout shift risks.

♿

Accessibility

axe-core WCAG checks plus alt text, contrast, labels, and heading structure.

🔍

SEO

Title, meta description, H1, canonical URL, Open Graph, and structured data.

✨

UX

Mobile viewport, tap targets, font sizes, forms, and horizontal scroll.

🎯

Click to locate

Click any issue in the popup to scroll to and highlight the element on the page.

🔒

Private by design

Nothing is sent to a server. Audits only run when you click the button.

How to install

Pick whichever method works best for you. No npm, no build step — the extension is ready to load as-is.

Easiest

Download ZIP

Download the extension folder as a ZIP, extract it, and load it in Chrome or Edge.

  1. Download ZIP from GitHub
  2. Unzip the file
  3. Open the inner page-audit folder (inside page-audit-main)
  4. Follow the “Load unpacked” steps below
Download ZIP

Load unpacked (Chrome)

For developers who already cloned the repo or extracted the ZIP.

  1. Open chrome://extensions
  2. Enable Developer mode (top right)
  3. Click Load unpacked
  4. Select the page-audit folder (contains manifest.json)
  5. Pin the extension from the puzzle icon

Microsoft Edge

Same extension works on Edge — no changes needed.

  1. Open edge://extensions
  2. Enable Developer mode
  3. Click Load unpacked
  4. Select the page-audit folder

Clone from GitHub

If you prefer git over downloading a ZIP.

git clone https://github.com/shubhransh-gupta/page-audit.git
cd page-audit/page-audit

Then load the page-audit folder via Load unpacked.

Open repository

Other Chromium browsers
