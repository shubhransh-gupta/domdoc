How to install

Choose the method that works best for you. No build step and no npm install.

Recommended

Download and load in Chrome

This is the fastest way to get started if you do not want to use the command line.

  1. Download the project as a ZIP file from GitHub.
  2. Unzip it on your computer.
  3. Open the folder named page-audit inside the unzipped folder.
  4. In Chrome, go to chrome://extensions.
  5. Turn on Developer mode.
  6. Click Load unpacked and select that page-audit folder.
Download ZIP

Microsoft Edge

Works the same way. Open edge://extensions, enable Developer mode, and load the same folder.

Clone with Git

If you already use git, clone the repository and load the inner page-audit folder.

git clone https://github.com/shubhransh-gupta/page-audit.git

How to use it

1

Install the extension

Add Page Audit to Chrome or Edge using one of the install methods above.

2

Open any website

Go to the page you want to check. Any normal public website works.

3

Click Test This Page

Open the extension popup and run the audit. Results appear in a few seconds.

4

Fix issues and re-run

Click an issue to find it on the page, fix it, and run the audit again.
