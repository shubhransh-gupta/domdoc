What is Page Audit?

This website tells you about the product. The extension is what you install in your browser to use it.

  • Website — you're here. Learn what it does and how to install.
  • Extension — a small add-on in Chrome/Brave/Edge that audits the current tab when you click Test This Page.

Page Audit is not a full CI Lighthouse replacement. It's fast, local feedback for everyday development — scores, issue lists, and click-to-highlight on the page. Powered by built-in heuristics and axe-core for accessibility.

Install the extension

No Node.js. No npm. No terminal. Just download and load.

Load the inner page-audit folder — the one that contains manifest.json, not the repo root.

Step-by-step (Chrome, Brave, or Edge)

  1. 1
    Download the extension

    Get the ZIP from GitHub and extract it on your computer.

    Download ZIP
  2. 2
    Unzip the file

    Extract to a folder you'll keep — e.g. page-audit-main/. Don't delete it after installing; Chrome loads the extension from this folder.

  3. 3
    Open extensions page
    • Chrome → chrome://extensions
    • Brave → brave://extensions
    • Edge → edge://extensions
  4. 4
    Enable Developer mode

    Toggle Developer mode in the top-right corner of the extensions page.

  5. 5
    Load unpacked

    Click Load unpacked and select page-audit-main/page-audit (the folder with manifest.json).

  6. 6
    Start auditing pages

    Pin the extension icon, visit any website, and click Test This Page.

Why isn't it on the Chrome Web Store?

Page Audit is distributed as open source for now. Install via the ZIP above — it's the same extension, just not listed in the store yet.

Do I need npm or Node.js?

No. All dependencies (including axe-core) are bundled. Download, unzip, and load.
