## Description

```
🩺 DOMDOC: PAGE AUDIT — One-Click Lighthouse for Developers

Stop guessing what's wrong with your website. DOMDoc gives you instant scores and actionable fixes — like Lighthouse, but one click away.

⚡ PERFORMANCE
• DOM size & page weight analysis
• Load time & request count
• Render-blocking script detection
• Layout shift risks (missing image dimensions)

♿ ACCESSIBILITY
• Powered by axe-core (WCAG 2a/2aa)
• Missing alt text, labels, contrast issues
• Heading structure & ARIA checks
• Click any issue to highlight the element on the page

🔍 SEO
• Title & meta description checks
• H1, canonical, Open Graph tags
• Structured data detection
• noindex warnings

✨ UX
• Mobile viewport & tap target size
• Font size & form usability
• Horizontal scroll detection

🎯 HOW TO USE
1. Click the DOMDoc icon on any website
2. Press "Test This Page"
3. Review scores and issues
4. Click issues to locate them on the page

🔒 PRIVACY FIRST
• 100% local — nothing leaves your browser
• No accounts, no tracking, no analytics
• Only runs when YOU click the button

Perfect for developers, designers, and QA teams who want fast feedback without opening DevTools.

Free. No npm. No build step. Just install and audit.
```
